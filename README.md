# 🎓 Student Performance Analyzer

## 📌 About the Project

This was built as **Assignment 1** for a Machine Learning course worksheet.  
The goal is to practice core Python concepts by building a small, practical program.

---

## 🛠️ Concepts Used

- Variables
- Input / Output
- Functions
- If-Else statements
- Lists

---

## ⚙️ How It Works

1. User enters the **student name**
2. User enters **marks for 5 subjects** (out of 100)
3. Program calculates:
   - Total marks
   - Percentage
   - Grade (A+, A, B, C, D, or F)
4. A **report card** is displayed at the end

---

## 🏆 Grading Scale

| Percentage | Grade |
|------------|-------|
| 90% and above | A+ |
| 80% - 89% | A |
| 70% - 79% | B |
| 60% - 69% | C |
| 50% - 59% | D |
| Below 50% | F |
